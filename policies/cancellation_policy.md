# Cancellation Policy

## When cancellation is available

An order may be cancelled at no charge only while its status is `placed`. A `placed` order has been accepted but has not yet entered the delivery network. The cancellation request should include the order number so the current status can be checked.

If cancellation is accepted, the order status changes to `cancelled`. No cancellation fee is charged. Any payment already captured for the cancelled order is returned to the original payment method according to normal banking processing times.

## After shipment

Once an order has the status `shipped`, it cannot be cancelled. The package is already with the carrier and cannot be recalled through the cancellation process. Refusing delivery does not create an approved cancellation and may delay resolution.

The customer must wait until the order is delivered and then request a return under the Returns Policy. The item must meet the return rules, including the 30-day window, unused condition, original packaging, and final-sale restrictions. Shipping charges are not automatically refundable when an order is returned after shipment.

## Other order statuses

An order with the status `delivered` is no longer eligible for cancellation because delivery is complete. An order marked `returned` has already gone through the return process and cannot also be cancelled. An order already marked `cancelled` requires no further cancellation request.

Submitting a request while an order is `placed` does not itself change the status. Cancellation is complete only when Kartly confirms it and the order shows `cancelled`.
